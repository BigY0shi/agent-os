# Content Writing

## Process
1. Clarify audience and channel from input.
2. Outline key points (3–5 bullets).
3. Draft copy in requested tone.
4. Self-check for clarity and CTA.

## Quality bar
- No unsubstantiated claims.
- Match brand voice from memory/context when provided.

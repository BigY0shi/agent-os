01

Pass 1 — Engineering

Nine read-only agents swept the core plumbing, the front page, all 224 API routes, the 13 agent workspaces, the Hermes/knowledge modules, and the work/output modules. An OpenAI-lineage critic (Codex) independently re-reviewed the core layer. Seven cross-cutting themes emerged.

1

Two lies to the owner

The home page fabricates fleet telemetry — store.ts:44 literally comments "Mock runtime numbers — replaced by real telemetry when the bridge is wired." The bridge was never wired: agent status is assigned by array index (agent #4 is always "error"), tokens and cost by formula. Separately, Jarvis hardcodes "Realtime voice is live — just talk" over a voice feed that is dead on this machine. Once one number is theater, none are trusted.

2

A macOS → Windows portability bug class

The shared spawn layer (runner.ts) is Windows-safe, but ~8 routes bypass it and reintroduce the exact macOS assumptions it was written to kill — producing 5 P0 failures: a hardcoded /usr/bin/python3, a macOS-only open, a Chrome path that silently disables Loop's browser check, an empty HOME that breaks Goal-mode, and a bare netlify/claude spawn. This is the single highest-yield engineering theme.

3

Chat-surface sprawl

~20 ways to talk to an agent: 1 shared component (UnifiedChat, reused 3×) + 8 bespoke reimplementations + 5+ orphaned/duplicate panels. CursorView and PiView are ~95% identical twins. A shared AgentPicker exists and is used by 12 files — but /room and /fusion hand-roll their own.

4

OpenRouter blast radius

One invalid key silently kills Fusion (P0), Free Claude, the Room's openclaw agent, the N2 build engine, and a Whisper fallback — because those paths have no CLI fallback, violating the project's own CLI-first rule. Everything CLI-shelled is unaffected, which proves the healthy design.

5

Loop-engine fragility

The autonomous core is the least trustworthy: Stop doesn't reach the CLI child (burns the full 600s), prompts over 32k chars are silently dropped (loops spin uselessly after iteration 1), the string "false" is read as a passing verdict, the Judge silently falls back to Ollama (Rule-11 violation, triggerable today), and the browser check is disabled on Windows.

6

Security: one password, full RCE — but cheap to fix

By design this app is a remote-code-execution service for the machine. The whole boundary is one brute-forceable password over cleartext HTTP, with a pass-the-hash cookie and a path-traversal to ~/.agentic-os secrets. Impact is total; the core fixes are hours, not weeks.

7

Rot & recoverability

~12 orphaned routes/components, 3 nav-orphaned but fully-built pages (/ruflo, /goals, /journal), and version control gone (empty .git). Countervailing good news: the .exile move-don't-delete discipline is intact and active through Jul 1 — nothing was truly lost.

CRITICAL BOARD · the P0s

P0

Front page renders fabricated telemetry

store.ts:44

5 of 8 widgets are pure fiction (fake KPIs, a random "live" event feed, recs for agents that don't exist); 3 dress real config with per-index fake status. A real feed (/api/activity) exists but the home page ignores it.

Fix Replace seedRuntime with honest status + wire the real activity feed. One move fixes 4 widgets.

P0

Version control wiped — .git is empty

.git/

No HEAD, no refs, no history since ~Jun 30. No diff, no rollback, no upstream pull. .exile backups are the only recovery net (intact through Jul 1).

Fix Re-clone upstream, exile current tree first, keep the remote (per Council ruling).

P0

Login has no rate-limit → brute-force = full RCE

api/auth/login/route.ts:14

The one password gating agent-spawn routes (with --yolo/--dangerously-skip-permissions) has no lockout, no throttle. Guess it → arbitrary code execution as the user.

Fix Per-IP backoff + lockout, entropy check, bind Tailscale-only.

P0

5 macOS-only spawns break on Windows

seo/research · realtime/open · loop/run · hermes+codex/goals · hyperframes

Hardcoded /usr/bin/python3, macOS open, macOS-only Chrome path (silently disables Loop's browser check), empty HOME, bare claude — all bypass the Windows-safe runner.ts.

Fix Route every spawn through runner.ts; delete the bespoke env-building.

P0

Fusion chat is dead on arrival

api/fusion/chat/route.ts

Its only path is the invalid OpenRouter key, no fallback. The "PANEL" model chips (Opus/Gemini/Grok/Fable) are a hardcoded client-side illusion — the backend calls one model id.

Fix Add a CLI fallback or an honest "not connected" state.

P0

Video pipeline broken end-to-end

api/video/hyperframes/render/route.ts:20

Render binary hardcoded to a Unix path (no Windows) → 503 on every render. HeyGen/MiniMax unconfigured → grids silently empty (errors swallowed to []).

Fix Portability fix + surface the errors the server already produces — or bundle/exile the studio.

SYNERGY GAPS · things that should connect but don't

GAP 01

Leads ✕ Deal Desk don't touch

Two separate prospecting systems with zero shared code. The flywheel's first two stages are a manual re-keying, not a pipe.

GAP 02

No won-deal → machine bridge

When a pitch lands there's no path to "spin up the machine for this client." The productization spine (CS Engine) lives in a repo the dashboard can't see.

GAP 03

No revenue truth anywhere

The home page fabricates tokens/cost, but there is no real "deals in flight / $ pipeline / machines shipped" view — the one thing a founder wants each morning.

The draft-never-send rule is honored, but the human-in-the-loop step happens in Gmail — the cockpit can't show "N drafts awaiting your review."

Third-Party Roadmap

An independent OpenAI-lineage engineer, given only the findings and none of my council's conclusions — a genuine outside opinion, including where it disagrees with me.

Outside eyes · Codex

  • Fix first: contain the RCE surface (Tailscale-bind, TLS, rate-limit, revocable sessions, route-level authz, reject traversal); make execution trustworthy (abort, tree-kill, oversized prompts, the "false" verdict, silent fallback) then remove the fabricated KPIs/statuses — "a control plane that can falsely report success is worse than one that reports failure"; restore recoverability + one runtime contract (git from .exile, route every spawn through the Windows-safe runner).
  • Build next: the revenue-to-machine vertical slice — lead → verified contact → approval-gated draft → won → client machine — one durable schema, only real counts on the home screen. (Converges with my council's Deal Flow ruling.)
  • Cut: freeze and exile Video/Music/Games/Open Design/Sakana/Fusion, the Local/FreeClaude duplicates, orphaned panels, dead routes, fake settings — keep recoverable, stop treating as product surface.
  • Biggest under-weighted risk: single-host blast radius — one Windows box holds source, credentials, vault, client artifacts, and privileged agents; a bad run or disk failure could destroy operations and expose customer data at once. Recovery drills, secret isolation, and sandboxed working dirs matter more than another feature.
  • Contrarian (disagrees with my council): do NOT build the One Agent Console yet — a universal UI refactor is expensive and capability-flattening; standardize the backend runner + telemetry contract, but preserve the native agent surfaces until usage proves them redundant.

# YoshiCorp Project Overview

**Company:** YoshiCorp (Parent) and subsidiaries: HexMod Studios, HexMod Labs, PayloadsCo, ExploitDepot, HackerOutlet, BlackhatWorkshop, HackN / Hackn.dev

**Principal:** Julian Golde (CEO / CoS)

**Mission:** A vertically-integrated offensive-security, hardware-hacking, and maker-education empire. Build tools, teach skills, sell gear — all under an anti-corporate, hackerman brand identity. Every product line must serve either a clear revenue goal or a strategic audience-building objective.

---

## Subsidiaries & Business Units

| Subsidiary | What It Does | Audience | Revenue Model |
|---|---|---|---|
| **HexMod Labs** | Cyberdeck Trinity (PocketHex, PalmHex, DeskHex), Flipper Zero modules, maker kits, custom PCBs | Hardware hackers, embedded devs, Flipper community | Hardware sales (Etsy, eBay, WooCommerce) |
| **HexMod Studios** | Video games (esp. extraction shooter: "The Quiet Professionals") | Gamers, creative hackers | Game sales, DLC, microtransactions |
| **PayloadsCo** | Offensive security hardware: malicious cables, Hak5 gear, physical security tools | Pentesters, red teamers, security researchers | Hardware sales + subscription content |
| **ExploitDepot / HackerOutlet / BlackhatWorkshop** | Darker/offensive gear, CTF tools, underground-leaning products | CTF players, red teamers, underground hackers | Hardware + digital product sales |
| **HackN / Hackn.dev** | Educational content: multi-article teaching modules, scripts, payloads, automation tools, content courses | Students, self-taught hackers, makers | Ad revenue, affiliate, course sales, Patreon-style subs |

## Current Assets & Infrastructure

- **AI Infrastructure:** Honcho LXC (192.168.0.99:8000), Ollama Cloud, local model routing, Hermes Agent stack, Paperclip agent runtime
- **Storefronts:** WooCommerce (WordPress), Etsy, eBay — with cross-platform inventory sync planned
- **Development:** Cyberdeck Trinity (ESP32-S3, Pi Zero 2W, Pi 5), Flipper Zero add-ons, PCB design pipeline
- **Content:** Hackn.dev platform (games, scripts, payloads, CMS)
- **Outbound:** ElevenLabs voice agent campaigns (local businesses — cybersecurity services, IT consulting)
- **Brand Identity:** Anti-corporate, dystopian megacorp, darkly humorous, self-aware. Never sanitized, never SaaS-startup.
